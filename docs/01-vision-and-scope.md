## 1. Бизнес-требования
 
### 1.1 Предпосылки

При приёмке контейнеров на РЦ регулярно обнаруживаются расхождения: недостача, повреждения при транспортировке, пересорт, брак, недокомплект. Претензионная работа с китайскими поставщиками ведётся полностью вручную: специалист ВЭД собирает претензионный пакет из 4–5 источников (1С, почта, папки с BOL, WhatsApp/WeChat, email-переписка), на один кейс уходит 4–8 часов.

### 1.2 Возможность для бизнеса
 
Модуль «Приёмка+» должен:
- автоматизировать сборку претензионного пакета (Evidence Pack) при утверждении расхождения — с 4–8 часов до минут;
- обеспечить 100% привязку расхождений к контракту, инвойсу, INCOTERMS и фотодоказательствам;
- дать ВЭД-специалисту единый инструмент управления всеми претензиями (канбан с SLA);
- поднять успешность претензий с ~50–60% до ≥ 85%;
- исключить пропуск контрактных сроков предъявления претензий.

### 1.3 Бизнес-цели и метрики успеха
 
| BG-# | Бизнес-цель | Метрика | 
|---|---|---|
| BG-01 | Не пропускать сроки претензий | % претензий, отправленных в рамках контрактного срока | 
| BG-02 | Повысить успешность претензий | Доля претензий с полным или частичным возмещением | 
| BG-03 | Сократить время сборки документов для отправки претензии | Медиана временного промежутка от начала сборки до отправки | 
| BG-04 | Полнота доказательной базы | % претензий с полным пакетом (фото + инвойс + ул + контракт) |
| BG-05 | Единая картина для ВЭД | Кол-во инструментов для ведения претензий | 
| BG-06 | Сократить цикл закрытия | Медиана «фиксация расхождения → закрытие претензии» | 

### 1.4 Vision Statement
 
> Для **специалистов ВЭД и руководителя отдела** «ТехноИмпорт», страдающих от **ручной сборки претензионных пакетов, пропуска контрактных сроков и разрозненного трекинга претензий**, **«Приёмка+»** — модуль претензионной работы, который **автоматически собирает Evidence Pack с Claim Letter при утверждении расхождения, ведёт все претензии на канбан-доске с SLA-таймерами и обеспечивает полный workflow от фиксации до закрытия с передачей итога в 1С**. В отличие от **ручного процесса через Excel + почту + Битрикс + WeChat**, наш модуль **сокращает время сборки претензии с 4–8 часов до минут, гарантирует полноту доказательной базы и не даёт пропустить контрактный дедлайн**.
