# Приёмка+ : Претензионная работа ВЭД


## О проекте

**Приёмка+** — модуль для управления претензиями к иностранным (китайским) поставщикам при обнаружении расхождений в импортных поставках.

**Компания:** ООО «ТехноИмпорт» — оптовый импортёр непродовольственных товаров (~20 поставщиков в Китае, 3–5 контейнеров в неделю, контракты в USD/CNY, условия FOB/CIF по INCOTERMS 2020).

*все названия и данные изменены для сохранения конфиденциальности проекта компании

### Бизнес-проблема

Обработка расхождений при приёмке импортных грузов и подготовка претензий — полностью ручной процесс. Специалист ВЭД собирает претензионный пакет из 4–5 источников (1С, почта, папки с BOL, WhatsApp/WeChat, email). На один кейс уходит **4–8 часов**, успешность претензий — **~50–60%**, а **20–30% возмещений** теряются из-за пропуска контрактных сроков.

### Решение

Модуль покрывает два связанных процесса:

1. **Фиксация расхождений** — структурированный ввод на ТСД с классификацией, фотофиксацией, привязкой к контракту и INCOTERMS.
2. **Претензионная работа ВЭД** — от автоматической сборки Evidence Pack до закрытия претензии с передачей итога в 1С.

### Целевые метрики

| Метрика | Текущее | Целевое |
|---------|---------|---------|
| Претензии, отправленные в срок | ~70% | ≥ 95% |
| Успешность претензий | ~50–60% | ≥ 85% |
| Время сборки Evidence Pack | 4–8 ч | ≤ 30 мин |
| Полнота доказательной базы | ~60% | ≥ 98% |
| Инструментов для ведения претензий | 4–5 | 1 |
| Медианный цикл закрытия | ~45 дней | ≤ 25 дней |

## Роль: BA/SA

Полный цикл работы бизнес-аналитика и системного аналитика — от исследования текущего процесса до готовой спецификации требований.
